શ્રી અડાઆઠમ દરજી સેવા સમિતિ, મોડાસા — પ્રથમ વેબ એપ ડેમો

ફાઇલો:
- index.html : મોબાઇલ અને કમ્પ્યુટર બંને માટે responsive વેબ એપ.

કમ્પ્યુટર પર ચલાવવું:
1. ZIP extract કરો.
2. index.html પર double-click કરો.
3. Chrome, Edge અથવા Firefoxમાં ખોલો.

Android મોબાઇલ પર:
- ZIP extract કરી index.html ખોલવા માટે file manager/browserનો ઉપયોગ કરી શકાય, પરંતુ આ સરળ રીત દરેક ફોનમાં સરખી રીતે ન ચાલે.
- શ્રેષ્ઠ અનુભવ માટે આ ફાઇલને વેબ હોસ્ટિંગ પર મૂકવી પડશે.

આ વર્ઝનની મર્યાદાઓ:
- આ UI/પ્રોટોટાઇપ છે; હજી online database અથવા સાચું સુરક્ષિત login જોડાયેલું નથી.
- દાખલ કરેલી માહિતી તે જ browser/deviceના local storageમાં જ સાચવાય છે. બીજા ફોન/કમ્પ્યુટરમાં આપમેળે દેખાશે નહીં.
- એડમિન વિભાગમાં ભૂમિકાઓ બતાવેલી છે, પરંતુ પ્રમુખ/મંત્રી/ખજાનચી માટે વાસ્તવિક authentication અને permissions હજી લાગુ નથી.
- વાસ્તવિક સભ્યોના ફોન નંબર, પાસવર્ડ, દાનની વિગતો અથવા અન્ય ખાનગી માહિતી આ demoમાં ન ઉમેરો.
- જાહેર ઉપયોગ પહેલાં backend, database, secure authentication, role-based access, backups અને privacy policy ઉમેરવી જરૂરી છે.

આગળનું પગલું:
આ પ્રોટોટાઇપ પસંદ થયા પછી તેને Firebase/Supabase જેવા database/backend સાથે જોડીને online બનાવવું અને પછી Android app package બનાવવાની યોજના બનાવી શકાય.
