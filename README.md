# અડોઠમ દરજી સમાજ — ડિજિટલ પોર્ટલ (Adaadtham Darji Samaj Web Portal)

સમાજના દરેક પરિવારને જોડતું એક આધુનિક, સુરક્ષિત અને સંપૂર્ણ ગુજરાતી ભાષા આધારિત ડિજિટલ પ્લેટફોર્મ.

**સંસ્થા:** શ્રી અડાઆઠમ દરજી સેવા સમિતિ, મોડાસા (જિ. અરવલ્લી, ગુજરાત)  
**સૂત્ર:** *“આપણો સમાજ, આપણો પરિવાર”*

---

## 🚀 વિશેષતાઓ (Key Features)

1. **સંપૂર્ણ ગુજરાતી ઇન્ટરફેસ (100% Gujarati UI)**
   - તમામ મેનુ, બટનો, ફોર્મ, માન્યતા સંદેશાઓ, ભૂલો અને એડમિન ડેશબોર્ડ શુદ્ધ ગુજરાતી ભાષામાં.
   - Google Font `Noto Sans Gujarati` સાથે ઉચ્ચ સ્તરીય ટાઇપોગ્રાફી અને દૃશ્યમાન સૌંદર્ય.

2. **ઇન્ટરેક્ટિવ પરિવાર વૃક્ષ (Interactive Family Tree with React Flow)**
   - સભ્યો અને પરિવારો વચ્ચેના સંબંધો (પતિ-પત્ની, માતા-પિતા, પુત્ર-પુત્રી, ભાઈ-બહેન, સાસુ-સસરા, નણંદ, ભાભી, બનેવી, કાકા-કાકી, મામા-મામી, ભત્રીજો-ભત્રીજી વગેરે).
   - ગ્રાફ વ્યૂ (ઝૂમ, પેન, સેન્ટર) અને મોબાઇલ-ફ્રેન્ડલી યાદી વ્યૂ (List View).
   - ડુપ્લિકેટ પ્રોફાઇલ બનતા અટકાવવા માટે અસ્તિત્વમાં રહેલા સભ્યોને જ સર્ચ કરી સંબંધ વિનંતી મોકલવાની સુવિધા.
   - સંબંધ રદ કરવાથી સભ્યનું મૂળ ખાતું કે અન્ય સંબંધો ડિલીટ થતા નથી.

3. **કડક ગોપનીયતા & પરવાનગી વ્યવસ્થા (Privacy & Permissions Matrix)**
   - ૪-સ્તરીય વિઝિબિલિટી:
     - **જાહેર (Public)**
     - **માત્ર લોગિન કરેલા સભ્યો (Members Only)**
     - **મંજૂર પરિવારના સભ્યો (Family Only)**
     - **ખાનગી (Private)**
   - ફોન નંબર, સરનામું, પ્રોફાઇલ ફોટો, પરિવાર સંબંધો, રોજગાર અને શૈક્ષણિક વિગતો માટે અલગ-અલગ સેટિંગ્સ.
   - બાળકોના શિક્ષણની વિગતો બાળ સુરક્ષા હેતુ ડિફોલ્ટ રૂપે સંપૂર્ણ ખાનગી.

4. **સમાજ વ્યવસાય ડિરેક્ટરી & સ્પોન્સરશિપ (Business Directory & Ads)**
   - કેટેગરી પ્રમાણે વ્યવસાયો (ટેલરિંગ, જ્વેલર્સ, ટેક્સટાઇલ, પ્રોવિઝન સ્ટોર, સીએ/એકાઉન્ટિંગ વગેરે).
   - પેઇડ એડવર્ટાઇઝમેન્ટ વર્કફ્લો: ચુકવણી ચકાસણી (Payment Verification) પછી જ જાહેરાતને ફીચર્ડ અને સક્રિય દરજ્જો.

5. **કાર્યક્રમો & ફોટો ગેલેરી (Events & Photo Gallery)**
   - આગામી અને સંપન્ન કાર્યક્રમો (વાર્ષિક સ્નેહમિલન, ચામુંડા માતાજી પાટોત્સવ, રક્તદાન શિબિર).
   - વર્ષ પ્રમાણે ફિલ્ટર, ફોટો આલ્બમ અને વિડિયો પ્રસારણ લિંક્સ.

6. **પારદર્શક દાન વ્યવસ્થા & દાતા યાદી (Donation Management)**
   - પાવતી જનરેશન અને બેંક ખાતા / UPI માહિતી.
   - દાતાની લેખિત સંમતિ વગર કોઈ પણ દાન સાર્વજનિક પ્રદર્શિત ન કરવાનો નિયમ. ગુપ્ત દાન (Anonymous) માટે સંપૂર્ણ સુરક્ષા.

7. **સત્તાવાર ૪ એડમિન હોદ્દેદારો & ઓડિટ લોગ (Role-Based Admin Dashboard)**
   - **પ્રમુખ શ્રી (President):** સર્વોચ્ચ સંચાલન, પરિવાર સંબંધ અને નીતિગત મંજૂરી.
   - **મંત્રી શ્રી (Secretary):** સભ્યો, સૂચનાઓ, પરિપત્રો અને કાર્યક્રમો.
   - **સહમંત્રી શ્રી (Joint Secretary):** સહાયક વ્યવસ્થા અને દસ્તાવેજ સંચાલન.
   - **ખજાનચી શ્રી (Treasurer):** દાન, બેંક ખાતા, પાવતી અને નાણાકીય હિસાબ.
   - વહીવટી પ્રવૃત્તિ નોંધ (Security Audit Trail): કયા એડમિને કઈ તારીખે શું ફેરફાર કર્યો તેનો સમય સાથે રેકોર્ડ.

## 🛠️ ટેકનોલોજી સ્ટેક (Tech Stack)

- **ફ્રેમવર્ક:** Next.js 14 (App Router)
- **ભાષા:** TypeScript & React 18
- **ડિઝાઇન:** Tailwind CSS (કસ્ટમ કેસરી/સેફ્રોન, ફોરેસ્ટ ગ્રીન, વોર્મ આઇવરી અને ડાર્ક ચારકોલ પેલેટ)
- **ચિહ્નો (Icons):** Lucide React
- **પરિવાર વૃક્ષ ગ્રાફ:** React Flow (`reactflow`)
- **આંકડાકીય આલેખ:** Recharts
- **ડેટાબેઝ & ઓથેન્ટિકેશન:** Supabase (PostgreSQL with Row Level Security)
- **ઓફલાઇન/ડેમો સ્થિતિ:** લોકલ સ્ટેટ અને બ્રાઉઝર સ્ટોરેજ સાથે સ્વતઃ સુમેળ

## 💻 લોકલ રન કરવાની રીત (Local Setup Instructions)

### ૧. નિર્ભરતાઓ ઇન્સ્ટોલ કરો:
```bash
npm install --legacy-peer-deps
```

### ૨. ડેવલપમેન્ટ સર્વર શરૂ કરો:
```bash
npm run dev
```
બ્રાઉઝરમાં ખોલો: `http://localhost:3000`

### ૩. પ્રોડક્શન બિલ્ડ તૈયાર કરવા અને ચલાવવા:
```bash
npm run build
npx next start -p 3000
```

## 🗄️ સુપાબેઝ સેટઅપ (Supabase Configuration & Database Migration)

૧. [Supabase](https://supabase.com) પર નવો પ્રોજેક્ટ બનાવો.  
૨. પ્રોજેક્ટ ડેશબોર્ડમાંથી **Project URL** અને **Anon Key** મેળવો.  
૩. `.env.local.example` ફાઇલને `.env.local` તરીકે કોપી કરો અને કી ઉમેરો:
```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key-here
```
૪. Supabase SQL Editor માં જઈને [`src/lib/database.sql`](file:///d:/AdaadthamSamaj/src/lib/database.sql) ફાઈલનો સમગ્ર કોડ રન કરો.  
તેમાં તમામ ટેબલ્સ (`members`, `family_relationships`, `businesses`, `events`, `donations`, `announcements`, `activity_logs`) અને Row Level Security (RLS) પોલીસી આપમેળે કન્ફિગર થઈ જશે.

## 🔒 સુરક્ષા અને પરવાનગીઓ (Security & Access Control)

- **રોલ આધારિત સુરક્ષા (RBAC):** જાહેર નોંધણી દ્વારા કોઈપણ વ્યક્તિ એડમિન બની શકતી નથી. એડમિન હોદ્દા માત્ર સમિતિ દ્વારા અધિકૃત વપરાશકર્તાઓને જ મળે છે.
- **ઓડિટિંગ:** સંવેદનશીલ ફેરફારો (જેમ કે સંબંધ મંજૂરી, દાન પુષ્ટિ, જાહેરાત મંજૂરી) એડમિનના નામ અને સમય સાથે ઓડિટ લોગમાં નોંધાય છે.
- **ડેટા સેફ્ટી:** સંવેદનશીલ અંગત વિગતો માટે સર્વર-સ્તરે ગોપનીયતા નિયમો લાગુ છે.
